# Como navegar no sistema

## Objetivo

Explicar como se localizar dentro do Harpia: o menu lateral, a busca de opções e a forma
como os caminhos são apresentados nesta documentação.

## O menu lateral

Todas as funcionalidades ficam no **menu lateral**, à esquerda da tela. O menu é organizado
em grupos (por exemplo: **Financeiro**, **Bancário**, **Tabelas**, **Relatórios**). Ao clicar
em um grupo, ele se expande e mostra as opções internas.

## Pesquisar uma opção

No topo do menu existe um campo **"Pesquisar opção"**. Ao digitar parte do nome de uma tela
(por exemplo, `boleto`), o menu passa a mostrar apenas as opções que correspondem ao texto,
mesmo que estejam dentro de grupos diferentes. Isso ajuda a chegar rápido a uma tela sem
precisar lembrar em qual grupo ela está.

## Como lemos os caminhos nesta documentação

Sempre que uma página indicar **como acessar** uma tela, o caminho é mostrado assim:

```
Financeiro
→ Recebimento de Mensalidade
```

Isso significa: abra o grupo **Financeiro** no menu lateral e clique em **Recebimento de Mensalidade**.

> **Atenção:** o menu é configurável por escola. Os nomes e a posição das opções podem variar
> conforme a configuração da sua instituição. Em caso de dúvida, use a busca de opções.
