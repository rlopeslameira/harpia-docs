# Introdução ao Harpia

## Objetivo

O **Harpia** é um sistema de gestão escolar que centraliza, em um único lugar, a
administração acadêmica, a secretaria e o setor financeiro da escola. Com ele a escola
faz matrículas, monta turmas, lança notas e frequência, emite documentos, gera boletos e
controla todo o fluxo de caixa.

## Para quem é o sistema

O Harpia é usado por diferentes perfis dentro da escola:

| Perfil | O que costuma fazer no sistema |
|--------|-------------------------------|
| Secretaria | Matrículas, turmas, documentos, histórico escolar |
| Financeiro | Recebimentos, boletos, contas a pagar, fechamento de caixa |
| Coordenação / Direção | Consulta de indicadores, relatórios, configurações |
| Professores | Lançamento de notas e frequência |

> As telas que cada usuário enxerga dependem das **permissões** definidas para o seu perfil.
> Se você não encontra uma opção citada nesta documentação, fale com o administrador da sua escola.

## Como está organizada a documentação

A documentação é dividida por **módulos**. Cada funcionalidade tem uma página própria que
explica o objetivo, quem pode usar, como acessar, o passo a passo, os campos, os botões, as
regras e as mensagens do sistema. Comece pelo [Índice geral](../README.md).
