# Roadmap da Documentação Completa — Harpia

Este documento controla o progresso da documentação funcional de **todo** o sistema.
A ordem segue a **jornada do usuário**: Cadastro → Acadêmico → Frequência/Notas/Boletim →
Secretaria/Histórico → Financeiro → Tabelas → Administrativo/Gerenciador → Configurações → Relatórios.
