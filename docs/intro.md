# Documentação do Harpia

Bem-vindo à documentação funcional do **Harpia**, o sistema de gestão escolar.

Esta documentação explica **como usar** o sistema. Ela é escrita para usuários finais,
equipe de suporte, implantação, treinamento, analistas de negócio, novos colaboradores e gestores.
Não descreve como o código foi implementado — descreve o comportamento do produto.

> **Observação:** o menu do Harpia é configurável por escola. Os caminhos indicados nesta
> documentação seguem a organização padrão do sistema. Se a sua escola tiver menus
> personalizados, os nomes podem variar, mas as telas e os fluxos são os mesmos.

:::tip Atualizações quentes
🔥 **Quer acompanhar as novidades mais recentes do Harpia?**
Veja a página de [Notas de versão](release-notes/2026-07.md) para conferir ajustes, melhorias e mudanças visíveis ao usuário.
:::

## Como esta documentação é mantida

A documentação é revisada **semanalmente** e sincronizada com o comportamento atual do
sistema. Apenas as páginas afetadas por mudanças visíveis ao usuário são atualizadas;
o histórico é sempre preservado no final de cada página e nas [Notas de versão](release-notes/2026-07.md).
