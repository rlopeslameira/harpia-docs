# Módulo Configurações

## Objetivo

O módulo **Configurações** define **como o sistema se comporta** em cada área: as regras de
**avaliação** e de **notas**, o layout do **boletim**, os **conceitos** e **convenções**, os
**parâmetros financeiros** e as **fórmulas** de cálculo (notas, frequência, financeiro). São
ajustes que valem para todo o sistema (ou por período) e afetam o resultado de várias telas.

## Como acessar

As telas ficam no grupo **Configurações** do menu lateral.

## Mapa do módulo

| Tela | Para que serve | Documentação |
|------|----------------|--------------|
| Configurações de Avaliações | Etapas avaliativas e fórmula Nota x Peso | [Abrir](avaliacoes.md) |
| Configurações de Conceitos | Conceitos (sigla ↔ faixa de nota) | [Abrir](conceitos.md) |
| Configurações de Convenções | Rótulos de aprovação/reprovação e do boletim | [Abrir](convencoes.md) |
| Configurações do Boletim | Colunas e layout do boletim impresso | [Abrir](boletim.md) |
| Fórmulas de Secretaria (Notas) | Fórmulas de cálculo das notas | [Abrir](formulas-secretaria.md) |
| Fórmulas de Frequência | Fórmulas de cálculo da frequência | [Abrir](formulas-frequencia.md) |
| Configurações do Financeiro | Parâmetros e regras do financeiro | [Abrir](financeiro.md) |
| Fórmulas do Financeiro | Fórmulas de cálculo financeiro | [Abrir](formulas-financeiro.md) |
| Configurações de Secretaria | Regras de matrícula, aprovação e cadastro | [Abrir](secretaria.md) |

> Muitas configurações têm escopo **Global** (todo o sistema) ou por **Período**. Confira o escopo
> antes de alterar.

## Atenção

Alterar configurações muda o **comportamento do produto** para todos os usuários. Teste em um
período/turma antes de aplicar amplamente, especialmente **fórmulas** e **parâmetros financeiros**.
